# Historical document snapshots

These preserve original investigation details, commands and measurements. They are
not current operational instructions. Start with [the current handoff](../HANDOFF.md).
Timestamps, PIDs and defaults inside them describe their own checkpoints. Some logs
and tools they reference are local ignored artifacts unavailable in a fresh clone.
Retail game data and generated binaries were never moved into this archive.
